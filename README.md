# Rekryteringscase – Försäkringsöversikt

En React- och TypeScript-applikation för att visa och filtrera en kunds försäkringar.

## Kom igång

Installera dependencies:

```bash
yarn install
```

Skapa en `.env`-fil i projektets rot med:

```env
VITE_API_BASE_URL=https://6a85c5b89c451dc67a64237c.mockapi.io
```

Starta utvecklingsservern:

```bash
yarn dev
```
